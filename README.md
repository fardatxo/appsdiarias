# appsdiarias

Dos proyectos por semana, avanzando un poco cada día: de lunes a miércoles un proyecto "clásico" (web HTML/CSS/JS, Python, Java o PHP) y de jueves a domingo un proyecto de **inteligencia artificial** en Python. Cada carpeta lleva la fecha en que se empezó e incluye su código comentado, un `PLAN.md` con los hitos diarios y un README con cómo ejecutarlo y qué se aprende.

Las primeras carpetas del repo son de la etapa anterior, cuando se hacía una app pequeña cada día.
